För att visa Google Maps i appen behövs en egen API-nyckel från Google (gratis upp till en generös månadsgräns, men kräver ett betalkort i Google Cloud). Så skaffar du en nyckel ↗. Aktivera "Maps JavaScript API". Nyckeln sparas bara i den här webbläsaren.

To show Google Maps in the app you need your own API key from Google (free up to a generous monthly limit, but it needs a payment card in Google Cloud). How to get a key ↗. Enable "Maps JavaScript API". The key is stored only in this browser.

Begränsa nyckeln så att ingen annan kan använda den: i Google Cloud, under API:er och tjänster → Inloggningsuppgifter, välj nyckeln och sätt Programbegränsningar till Webbplatser (HTTP-referrer) med bara din egen domän, t.ex. https://yukireport.com/*. Begränsa den gärna också till Maps JavaScript API.

Restrict the key so nobody else can use it: in Google Cloud, under APIs & Services → Credentials, pick the key and set Application restrictions to Websites (HTTP referrers) with only your own domain, e.g. https://yukireport.com/*. Preferably restrict it to the Maps JavaScript API as well.
